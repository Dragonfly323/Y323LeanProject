# Y323LeanProject
Lean Code for the family of objects inspired by Y323. The sections up to 32 have been finalized with Aristotle.Harmonic.Fun while 33 onward consists of sketches yet to be finalized. No math has needed correction in the finalization process so far, only programmatic polish.

Before accuracy can be established, perspective must take form, simply to say that framing is tantamount to not losing the forest for the trees, and thus poetic phrasings are at times used generously where appropriate, such as when dealing with higher dimensional structures. 

The greater work explores a simple yet vast mathematical structure that aligns with physical patterns and allows for complex dynamical systems. Currently lacking the time and resources to fully pursue this as I would like, I am sharing what I have now to facilitate community research into this field of novel mathematics.

Note about the original uploader: I have managed this work so far with zero dollars and only free-tier LLMS and limited internet access. I understand the underlying structure and help guide machines the best I can to put those structures into verifiable mathematics. 

Due to the scale of the work, I have reached a barrier where my lack of resources has slowed what progress and polishing I can perform within the greater mathematical work (as the Lean code is just a portion of the math so far). I would like to pursue this full time, with proper backing and a proper work environment. Until such time comes, I release what I've managed so far, and hope to release more over the days, weeks, months, and years.
